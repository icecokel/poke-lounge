## 검증 메모

- 운영 모바일 레이아웃의 대기실 프레임은 390×844에서 화면 밖으로 넘치지 않고, 하단 조작 dock도 별도 행으로 유지됐다.
- 첫 실행 중 준비 단계에서 이동해 야생 전투로 진입한 건은 테스트 러너 실수(`TEST-RUNNER`)로 분류하고 제품 결함에서 제외했다.
- 최종 결과 화면에서 확인한 공개 랭킹 상태는 `공개 랭킹 미반영`이었다. 운영 랭킹 반영 여부는 이번 UI 테스트 범위에서 확인하지 않았다.
