# Poke Lounge 화면 경계 정책

## 적용 범위

이 정책은 Poke Lounge의 웹·모바일 게임 화면, 모달, 메뉴, 선택지, 카드 목록에 적용한다.

## 핵심 원칙

- 게임 화면의 실제 경계는 브라우저 뷰포트가 아니라 `.gameFrame`과 `#game-root`다.
- 웹과 모바일 모두 상위 게임 화면에 스크롤이 없더라도, 필수 콘텐츠가 그 경계 밖으로 나가거나 잘려서는 안 된다.
- 페이지나 `#game-root`의 스크롤을 콘텐츠 접근 수단으로 사용하지 않는다.
- 선택지처럼 개수가 늘어날 수 있는 콘텐츠는 내부 목록을 제한하고 스크롤 가능하게 만든다. 개수가 고정된 콘텐츠는 반응형 크기·열 수·간격으로 경계 안에 맞춘다.

## 구현 기준

- 고정 게임 화면은 부모 프레임 기준의 명시적 높이를 사용한다. 앱 셸의 UI 높이를 무시하는 `100dvh`만으로 크기를 정하지 않는다.
- grid 또는 flex 자식이 남은 영역을 사용해야 하면 부모와 자식에 필요한 `min-height: 0`을 둔다.
- 내부 목록에는 제한된 높이와 `overflow-y: auto`를 함께 둔다. 스크롤 대상은 목록만으로 제한하고, 시작·확인 같은 핵심 조작은 프레임 안에 유지한다.
- 모바일은 데스크톱 레이아웃을 축소만 하지 말고, 열 수·미리보기 크기·간격을 조정해 같은 경계 규칙을 만족시킨다.

## 검증 기준

- 데스크톱과 모바일에서 화면의 `getBoundingClientRect()`가 `#game-root` 경계 안에 있어야 한다.
- 동적으로 늘어나는 목록은 마지막 항목까지 내부 스크롤로 도달할 수 있어야 한다.
- 문서와 본문에 가로 오버플로가 없어야 하며, 키보드와 터치로도 가려진 조작을 사용할 수 있어야 한다.
