# Poke Lounge 3라운드 챔피언십 규칙

확인 기준일: 2026-08-31

상위 문서: [Poke Lounge 게임 규칙 인덱스](./index.md)

## 1. 라운드의 의미

챔피언십은 게임 라운드를 정확히 세 번 진행한다. 여기서 게임 라운드는 단일 매치가 아니라
다음 세 단계를 합친 단위다.

```text
준비 3분
→ 4인 또는 8인 싱글 엘리미네이션 토너먼트
→ 남은 체력 비율 점수 반영
```

토너먼트 안의 1회전·준결승·결승은 **토너먼트 단계**다. 이것을 1·2·3게임 라운드와 혼동하지
않는다.

## 2. 전체 순서

```text
대기실에서 전원 ready
→ 방장이 1라운드 시작
→ 1라운드 준비 3분
→ 1라운드 토너먼트
→ 1라운드 남은 체력 비율 점수 반영
→ 2라운드 준비 3분
→ 2라운드 토너먼트
→ 2라운드 남은 체력 비율 점수 반영
→ 3라운드 준비 3분
→ 3라운드 토너먼트
→ 3라운드 남은 체력 비율 점수 반영
→ 누적 점수 최종 순위
→ 최종 1위 우승
```

1·2라운드가 끝났다는 이유로 우승자를 조기 확정하지 않는다. 세 라운드를 모두 마친 뒤에만
최종 순위와 우승을 확정한다.

## 3. 라운드 준비

- 1라운드를 포함해 각 라운드 준비 시간은 3분, 즉 `180,000ms`다.
- 1라운드 준비는 대기실 참가자가 모두 ready를 선택한 뒤 방장이 시작한다.
- ready만으로 준비 시간을 자동 시작하지 않는다.
- 방장 시작 시 서버가 모든 참가자에게 같은 시작·종료 시각을 확정한다.
- 준비 종료 5초 전에는 현재 참가자 기준 예상 8강·4강·결승 단계를 모든 화면에 안내하고,
  카운트다운 종료 뒤 서버가 확정한 대진으로 전투를 시작한다.
- 정상적으로 1·2라운드를 완료하면 다음 라운드의 3분 준비는 자동 시작한다.
- 준비 중에는 월드를 탐색하고 포켓몬을 포획·성장·회복하며 파티를 편성할 수 있다.
- 준비 종료 시점까지 서버에 반영된 최신 파티를 해당 라운드의 frozen party로 사용한다.
- 파티는 1~6마리이며 선두 포켓몬은 전투할 수 있는 상태여야 한다.
- 종, 레벨, physical slot, 선두, IV, 기술, HP, 상태와 남은 PP를 그대로 동결한다.
- 레벨 보정, 임의 포켓몬 교체와 고정 파티 fallback을 사용하지 않는다.
- 준비 마감 시 유효한 파티가 없는 참가자가 있으면 임의 파티로 경기를 시작하지 않는다.

방장 시작 뒤에는 신규 참가자를 받지 않는다. 준비 중 이탈로 참가자가 2명 미만이 되면 현재
준비를 취소하고 대기실로 돌아간다. 남은 참가자의 ready를 해제하며, 참가자가 다시 준비한 뒤
방장이 현재 라운드의 새 3분 준비를 시작한다.

## 4. 토너먼트 대진

- 방 시작 시 현재 사람과 수동 AI가 1~~3명이면 4명까지, 4~~7명이면 8명까지 AI를 자동 추가한다.
- 토너먼트 참가 인원은 4명 또는 8명이다.
- 각 게임 라운드는 싱글 엘리미네이션으로 진행한다.
- seed는 참가 순서와 player ID로 안정적으로 결정한다.
- 4인은 `4강 2경기 → 결승`, 8인은 `8강 4경기 → 4강 2경기 → 결승`으로 진행한다.
- 자동 충원으로 bracket 크기를 맞추므로 부전승을 만들지 않는다.
- 같은 토너먼트 단계의 모든 1:1 매치는 서버가 동시에 활성화한다.
- 현재 단계의 모든 매치가 끝난 뒤 다음 단계의 매치를 동시에 활성화한다.
- 전투 중이 아닌 참가자는 현재 진행 중인 매치 하나의 같은 Battle scene을 입력 잠금
  상태로 안정적으로 관전한다.
- 매치 승자는 다음 토너먼트 단계로 진출하고 패자는 해당 게임 라운드에서 탈락한다.
- 마지막 매치 승자가 해당 게임 라운드 토너먼트 1위가 된다.

한 토너먼트 안의 모든 매치는 같은 frozen party에서 시작한다. 앞선 매치에서 발생한 HP 피해,
PP 소비, 상태와 선두 변경은 다음 매치나 월드 파티에 누적하지 않는다.

## 5. 라운드 체력 점수

라운드 점수는 각 사용자가 해당 게임 라운드에서 마지막으로 진행한 매치의 terminal party
snapshot을 기준으로 계산한다. 그 파티에 남은 체력 비율을 모두 더한다.

```text
포켓몬 점수 = 현재 HP ÷ 최대 HP × 100
라운드 점수 = Σ(파티에 포함된 모든 포켓몬 점수)
```

예를 들어 세 마리의 남은 체력이 각각 `100%`, `50%`, `0%`라면 라운드 점수는 150점이다.

- 전투불능 포켓몬은 0점이다.
- 체력이 가득 찬 포켓몬은 한 마리당 100점이다.
- 6마리 파티의 라운드 최대 점수는 600점이다.
- 세 라운드 최종 누적 최대 점수는 1,800점이다.
- 파티가 1~5마리면 실제 파티원만 합산한다.
- 토너먼트 최종 순위에 따른 고정 배점을 사용하지 않는다.
- 매치 terminal의 승자 100점·패자 50점도 챔피언십 점수에 더하지 않는다.

## 6. 누적 점수와 최종 우승

1. 각 라운드의 체력 점수를 기존 누적 점수에 정확히 한 번 더한다. 점수 반영은 해당 라운드의
   마지막 매치가 종료되는 즉시 완료한다.
2. 1·2라운드가 끝나면 현재 누적 순위를 표시하고 다음 3분 준비로 이동한다.
3. 3라운드가 끝나면 누적 점수 내림차순으로 최종 순위를 만든다.
4. 최종 순위 1위가 우승한다.
5. 누적 점수가 같으면 같은 순위를 부여하며, 최고 점수가 같으면 공동 우승으로 처리한다.

## 7. 매치 종료

매치 종료 사유와 판정은 [전투 규칙의 경쟁 매치 종료](./battle-rules.md#10-경쟁-매치-행동-시한과-종료)를
따른다. 종료 뒤 bracket 전진과 라운드 점수 반영은 서버가 한 번만 확정한다.

## 8. 저장과 중복 방지

- 매치 terminal, bracket 전진, HP snapshot, 라운드 점수와 다음 상태를 서버가 확정한다.
- 클라이언트가 승자, 점수나 최종 우승자를 직접 제출하지 않는다.
- 같은 매치 결과와 같은 라운드 점수를 새로고침·재접속 때문에 두 번 반영하지 않는다.
- UI, 공개 서버 snapshot과 Redis room 상태의 누적 점수·최종 순위가 같아야 한다.
