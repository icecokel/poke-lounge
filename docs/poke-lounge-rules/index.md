# Poke Lounge 게임 규칙 인덱스

확인 기준일: 2026-09-02

## 1. 문서 역할

이 문서는 Poke Lounge 전체 게임 규칙의 시작점이다. 게임 진행 순서와 고정 수치는 이
문서에서 먼저 확인하고, 세부 규칙은 연결된 하위 문서에서 확인한다.

이 디렉터리는 제품 게임 규칙만 관리한다. 현재 구현 상태는
[Poke Lounge 게임 콘셉트](../poke-lounge-game-concept.md), 테스트 절차는
[플레이어 E2E 테스트 시나리오](../poke-lounge-multiplayer-test-scenarios.md)에서 관리한다.

과거 계획서는 구현 배경으로만 사용한다. 규칙 값은 이 인덱스와 연결 문서를 기준으로 한다.

## 2. 게임 전체 진행

```text
솔로 또는 멀티플레이 탭 선택
→ 멀티플레이는 닉네임 + 임시 비밀번호 입력
→ 최대 6명이 같은 대기실에 자동 참가
→ 현재 파티 동기화 및 플레이어별 준비
→ 방장이 1라운드 시작
→ 1라운드 준비 3분 동안 탐색·포획·성장·파티 편성
→ 1라운드 싱글 엘리미네이션 토너먼트
→ 1라운드 종료 시 남은 체력 비율 점수 반영
→ 2라운드 준비 3분
→ 2라운드 토너먼트 및 점수 반영
→ 3라운드 준비 3분
→ 3라운드 토너먼트 및 점수 반영
→ 3라운드 누적 점수 최종 순위
→ 최종 1위 우승
```

한 라운드는 단일 전투 한 번이 아니다. 한 라운드는 `준비 3분 + 2~6인 싱글 엘리미네이션
토너먼트 + 남은 체력 비율 점수 반영` 전체를 뜻한다.

## 3. 핵심 규칙

| 영역           | 규칙                                                                          |
| -------------- | ----------------------------------------------------------------------------- |
| 입장           | 기본 솔로 화면에서 멀티플레이 탭을 고른 뒤 닉네임과 임시 비밀번호를 입력한다. |
| 계정           | Google 로그인, 계정 비밀번호와 사용자에게 보이는 방 코드는 사용하지 않는다.   |
| 인원           | 멀티플레이 세션은 최대 6명이며 7번째 신규 사용자는 거부한다.                  |
| 서비스 용량    | 동시에 유지하는 활성 room은 최대 20개다.                                      |
| 대기실         | 첫 참가자가 방장이며 2~6명이 모두 준비해야 방장이 시작할 수 있다.             |
| AI 참가자      | 방장이 대기실에서 추가·제거하며 서버가 사냥·포획·챔피언십 행동을 수행한다.    |
| 참가 잠금      | 방장 시작 뒤에는 준비·토너먼트가 끝날 때까지 신규 참가를 받지 않는다.         |
| 개인 진행      | 파티·PC 박스·재화·인벤토리·야생전은 사용자마다 따로 유지한다.                 |
| 공유 상태      | 닉네임·월드 위치·방향·방장·준비·참가 상태를 같은 세션에 공유한다.             |
| 파티           | 1~6마리이며 포켓몬 한 마리는 기술을 최대 4개 가진다.                          |
| 게임 라운드    | 반드시 1·2·3라운드를 모두 진행한다.                                           |
| 라운드 준비    | 각 라운드 전 준비 시간은 3분이다.                                             |
| 라운드 경기    | 준비 종료 시 파티를 동결하고 2~6인 싱글 엘리미네이션을 진행한다.              |
| 라운드 점수    | 각 포켓몬의 남은 체력 비율을 백분율로 환산해 모두 더한다.                     |
| 누적 점수      | 세 라운드의 남은 체력 비율 점수를 사용자별로 더한다.                          |
| 최종 우승      | 3라운드 종료 후 누적 점수 최종 순위 1위가 우승한다.                           |
| 공개 전체 랭킹 | 방 안의 누적 점수와 서비스 전체 공개 랭킹은 별개다.                           |

## 4. 라운드 점수

```text
포켓몬 점수 = 현재 HP ÷ 최대 HP × 100
라운드 점수 = 파티에 포함된 모든 포켓몬 점수의 합계
최종 점수 = 1라운드 점수 + 2라운드 점수 + 3라운드 점수
```

- 전투불능 포켓몬은 현재 HP가 0이므로 0점이다.
- 체력이 가득 찬 포켓몬 한 마리는 100점이다.
- 6마리 파티의 라운드 최대 점수는 600점이다.
- 세 라운드 최종 누적 최대 점수는 1,800점이다.
- 파티가 1~5마리면 실제 파티원 수만큼만 합산한다.
- 토너먼트 최종 순위 배점과 매치 승자·패자 고정 점수는 사용하지 않는다.

## 5. 용어 구분

| 용어          | 의미                                                            |
| ------------- | --------------------------------------------------------------- |
| 세션          | 같은 임시 비밀번호로 연결된 최대 6명의 공간                     |
| 대기실        | 준비 타이머 전 참가자·방장·준비 상태를 확인하는 `waiting` 단계  |
| 방장          | 대기실에서 시작 권한을 가진 가장 먼저 입장한 현재 참가자        |
| 게임 라운드   | 준비 3분, 한 번의 전체 토너먼트와 점수 반영을 묶은 단위. 총 3회 |
| 토너먼트 단계 | 한 게임 라운드 안의 1회전·준결승·결승 같은 bracket 단계         |
| 매치          | 두 사용자가 한 명의 승자가 결정될 때까지 진행하는 전투          |
| frozen party  | 라운드 준비 종료 시 서버가 검증하고 동결한 실제 육성 파티       |
| 라운드 점수   | 한 게임 라운드 종료 시 파티의 남은 체력 비율을 모두 더한 점수   |
| 누적 점수     | 1~3라운드 라운드 점수의 합계                                    |
| 최종 순위     | 3라운드가 끝난 뒤 누적 점수 내림차순으로 정렬한 순위            |
