# Poke Lounge 전투 규칙

확인 기준일: 2026-08-31

상위 문서: [Poke Lounge 게임 규칙 인덱스](./index.md)

## 1. 전투 종류

| 전투            | 목적                         | 결과 반영                             |
| --------------- | ---------------------------- | ------------------------------------- |
| 야생전          | 포획·경험치·재화 획득        | 개인 파티·인벤토리·재화에 반영        |
| 솔로 트레이너전 | 현재 성장 파티로 챌린지      | 개인 게임 결과에 반영                 |
| 경쟁 매치       | 챔피언십 토너먼트의 2인 전투 | 서버가 승패를 확정하고 bracket을 전진 |

## 2. 공통 파티 규칙

- 파티에는 1~6마리를 배치한다.
- 포켓몬 레벨은 1~100이다.
- 포켓몬 한 마리는 기술을 최대 4개 보유한다.
- 기술은 각각 남은 PP를 가진다.
- 현재 포켓몬, 빈 슬롯, 전투불능 포켓몬으로는 교체할 수 없다.
- 활성 포켓몬이 쓰러져도 살아 있는 파티원이 있으면 전투를 계속한다.
- 파티 전체가 전투불능이 되면 패배한다.

## 3. 야생·솔로 전투 명령

기본 명령은 `싸운다 / 가방 / 포켓몬 / 도망`이다.

| 명령   | 규칙                                                                 |
| ------ | -------------------------------------------------------------------- |
| 싸운다 | PP가 남은 기술을 선택해 사용한다.                                    |
| 가방   | 회복·상태 회복·부활·포획 아이템을 사용한다.                          |
| 포켓몬 | 전투 가능한 다른 파티원으로 교체한다.                                |
| 도망   | 야생전에서 도주 판정을 수행한다. 실패하면 상대 행동 기회를 소비한다. |

트레이너전과 경쟁 매치에서는 포획과 도주를 사용할 수 없다. 아이템 사용, 포획 실패와 도주 실패는
상대 행동 기회를 소비한다.

## 4. 턴과 대미지

전투는 Gen 4풍 규칙을 사용한다.

- 기술 우선도와 스피드 기반 행동 순서
- 명중·회피 단계와 명중 판정
- 물리·특수 분류에 따른 공격·방어 능력치
- STAB와 Gen 4 타입 상성
- 급소와 85~100% 대미지 난수
- 공격·방어·특수공격·특수방어·스피드·명중·회피 능력 단계
- 독·화상·마비와 턴 종료 잔여 피해

경쟁 매치는 양쪽 행동을 받은 뒤 다음 순서로 한 턴을 확정한다.

1. 행동 유효성 검증
2. 양쪽 교체 적용
3. 기술 우선도·스피드·동률 순서 결정
4. 마비 행동 불가 판정
5. PP 차감
6. 명중·급소·대미지·부가 효과 적용
7. 독·화상 잔여 피해 적용
8. 강제 교체 또는 매치 종료 확정

## 5. 상태와 능력 단계

지속 상태는 `normal`, `poisoned`, `burned`, `paralyzed`, `fainted`를 사용한다.

- HP가 0이면 상태는 `fainted`다.
- HP가 남아 있으면 `fainted`일 수 없다.
- 독과 화상은 턴 종료 피해를 준다.
- 화상은 물리 공격 대미지를 줄인다.
- 마비는 스피드와 행동 가능 여부에 영향을 준다.
- 능력 단계는 -6부터 +6까지만 변한다.

## 6. 기술 지원 범위

경쟁 카탈로그는 전국도감 1–493번 종과 1–470번 기술을 사용한다.

- 기술의 실제 ID, 이름, 타입, 분류, 위력, 명중률과 PP를 유지한다.
- 지원하는 상태·능력 단계 부가 효과는 실제로 적용한다.
- 지원하지 않는 부가 효과가 붙은 공격 기술은 기본 대미지만 적용한다.
- 지원하지 않는 순수 상태 기술은 ID와 PP를 유지하지만 선택할 수 없다.
- 선택 가능한 기술의 PP가 모두 0일 때만 `struggle`을 사용한다.
- `struggle`은 위력 50, 명중률 100이며 최대 HP의 1/4을 반동으로 소비한다.

## 7. 포획

포획은 상대 HP, 종족 포획률과 볼 배율을 사용하는 Gen 4식 네 번의 흔들림 판정으로 결정한다.
포획에 성공하면 파티에 빈자리가 있을 때 파티에 들어가고, 파티가 가득 차 있으면 PC 박스로
이동한다.

## 8. 야생전 결과와 필드 복귀

| 결과 | 개인 상태 반영                                                                           | 필드 복귀                                  |
| ---- | ---------------------------------------------------------------------------------------- | ------------------------------------------ |
| 승리 | 상대를 쓰러뜨린 경험치·포켓달러, 전투 후 HP·PP·상태를 저장한다.                          | 조우 전 좌표                               |
| 도망 | 보상과 포획은 없으며 실패 시 받은 피해·소모 상태는 저장한다.                             | 성공 시 조우 전 좌표                       |
| 포획 | 선택한 볼을 1개 소비하고 포켓몬과 쓰러뜨리기 보상의 절반인 돈을 저장한다. 경험치는 없다. | 조우 전 좌표                               |
| 패배 | 전멸한 파티의 HP·PP·상태를 저장하고 보상은 주지 않는다.                                  | `town`의 회복 지점 `(640, 304)`, 뒤쪽 방향 |

- 볼은 포획 결과가 결정되기 전에 선택 시점에 소비한다. 포획 실패 뒤에는 상대가 행동한다.
- 도주는 플레이어 스피드가 상대 이상이면 첫 시도가 성공하고, 그보다 느리면 시도 횟수에 따른
  판정을 수행한다. 실패하면 상대가 행동한 뒤 다시 선택할 수 있다.
- 패배 뒤에는 파티를 자동 회복하지 않는다. 필드 간호사와 상호작용해야 회복된다.
- 모든 결과는 `전투가 종료되었다. 확인을 누르면 필드로 돌아간다.` 확인 뒤 필드 상태에 반영한다.

## 9. 경쟁 파티

경쟁 매치는 해당 게임 라운드 준비 종료 시점의 frozen party를 사용한다.

- 종, 레벨, physical slot, 선두 슬롯, IV, 기술 ID, HP, 상태와 PP를 보존한다.
- 서버는 최대 HP, 파생 능력치, 타입과 기술 상한을 카탈로그로 계산한다.
- 잘못된 파티를 고정 파티로 대체하지 않고 경기를 시작하지 않는다.
- 한 토너먼트의 다음 매치는 같은 frozen party의 초기 상태에서 다시 시작한다.
- 경쟁 매치의 피해·PP·상태·선두 변경은 다음 매치나 월드 파티에 누적하지 않는다.

다음 게임 라운드는 다시 3분 준비를 거친 뒤 최신 파티를 새로 동결한다.

## 10. 경쟁 매치 행동 시한과 종료

각 턴은 서버가 연 시점부터 30초의 행동 선택 시한을 가진다. 시한 안에 제출하지 않은 플레이어는
그 턴의 행동만 사용하지 못한다. 한 명만 제출했다면 그 행동을 처리하고, 둘 다 제출하지 않았다면
행동 없이 턴 종료 효과만 처리한 뒤 다음 턴으로 진행한다. 행동 시한 만료 자체는 승패나 점수 사유가
아니다.

| 사유      | 규칙                                                     |
| --------- | -------------------------------------------------------- |
| `faint`   | 한쪽 파티 전체가 전투불능이면 상대가 승리한다.           |
| `forfeit` | 참가자가 나가거나 경기 지속 조건을 잃으면 상대가 이긴다. |

챔피언십 점수는 승패 고정 점수를 사용하지 않는다. 각 라운드 종료 시 파티의 남은 체력 비율을
합산하며 자세한 산식은 [3라운드 챔피언십](./three-round-championship.md)을 따른다.
